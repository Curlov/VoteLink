# VoteLink
voteLink ist eine einfache Webanwendung zum Erstellen und Teilen von Online-Abstimmungen. Nutzer können schnell eine Frage mit mehreren Antwortmöglichkeiten anlegen, den Abstimmungslink per Messenger, E-Mail oder Social Media teilen und die Ergebnisse übersichtlich als Diagramm anzeigen lassen.
